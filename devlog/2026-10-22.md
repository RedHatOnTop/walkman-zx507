## First-run setup and the first home screen (19:5x-20:2x)

The owner: a fresh home screen should stay as it is now, W.music and Sound adjustment only,
and a clean install that skips setup is not right. Pages chosen: language, time zone, Wi-Fi
and USB debugging.

- Stock 4.06's first boot is Google's SetupWizard with Sony's pages in it (`SonyWizardInteg`
  answers `com.android.setupwizard.action.PARTNER_CUSTOMIZATION`); the GSI has neither. Its
  `com.android.provision` (`/system/system_ext/priv-app/Provision`, HOME at priority 1) marks
  the unit set up without a page, so the release build came up in en-US on GMT.
- The home screen on the unit was not a default: nothing answers Launcher3's
  `PARTNER_CUSTOMIZATION` or `PLAY_AUTO_INSTALL`, so that layout lived only in the launcher's
  database.
- `apps/setup` (ZX507Setup), one activity, HOME at priority 2 with `SETUP_WIZARD`:
  - language: `LocalePicker.updateLocales` by reflection, 19 left-to-right languages the
    framework has;
  - time zone: ICU's canonical zones for the language's country, then all of them; a choice
    sets `auto_time_zone` 0;
  - Wi-Fi: Settings' `PICK_WIFI_NETWORK`, the page reading the state once a second;
  - USB debugging: `adb_enabled`, with `development_settings_enabled` when on;
  - done: `device_provisioned` 1, `user_setup_complete` 1, the activity disabled. A unit that
    is already set up gets that at once, so an update over a running image shows no page.
- The same package is Launcher3's partner package: `res/xml/partner_default_layout.xml`, dock
  places 1 and 2, W.music (`.activity.InitActivity`) and Sound adjustment
  (`.activity.SoundEffectMainActivity`), with attributes without a namespace, which
  `DefaultLayoutParser` reads after its own.
- Tried on the unit as an installed app (the platform key grants every permission it asks
  for), with `device_provisioned` and `user_setup_complete` at 0 for the run:
  - `updateLocales` was refused: "updatePersistentConfiguration() ... requires
    android.permission.WRITE_SETTINGS". Android 13 checks it besides `CHANGE_CONFIGURATION`;
    with it the page turned Korean in place.
  - Seoul moved the status bar clock to 20:04 (`persist.sys.timezone` Asia/Seoul,
    `auto_time_zone` 0).
  - Settings' picker opened as "Wi-Fi 선택" in the system's black and gold; back on the page,
    Wi-Fi on without a network read "연결되지 않음".
  - Korean broke between any two syllables ("설치할 수 있습니" / "다."). Word joiners inside
    Hangul words leave only the spaces to break at (CSS keep-all); checked again on the unit.
  - "시작하기": provisioned 1/1, the activity disabled, Launcher3 in front.
  - Then the unit was put back (en-US, automatic time zone on, Wi-Fi off, the app removed),
    except the time zone: Asia/Seoul rather than the unset GMT.
- `scripts/setup-gsi.sh` takes Provision out and puts the app in `/system/priv-app/ZX507Setup`
  with its privapp-permissions; step 21 of 27, after the QS tiles. The APK is the same bytes
  from three builds in two time zones (054bae20…); prebuilt-2 carries it beside prebuilt-1's
  four files, which this host's NDK (21.4) could not rebuild.
- A whole release build with the kit from this checkout and the owner's inputs: 407 s, 27
  steps; the image has the APK and no Provision.
- Not run yet: the setup as the first boot of a clean install, and the partner layout, which
  Launcher3 reads only into an empty database.
